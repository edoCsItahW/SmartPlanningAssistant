# 访谈记录

## 第一阶段

1. **目标用户：** 您认为这个产品主要是为哪一类用户群体服务的？（例如：自由职业者、小团队、项目经理、创意工作者？）**请尽可能精确。**
    需要对一段时间（几天几周甚至更长）进行个人计划、帮助自己管理时间和任务，并在其中找到最适合自己方案的用户。
    
2. **核心价值：** 对于您说的【目标用户】，他们目前在任务和时间管理上最大的**痛苦**是什么？我们的产品能为他们提供什么**独一无二的价值**来解决这些痛苦？
    目标和任务有各自的特点，有些紧迫，有些需要条件，有些有前置任务等等，还要考虑娱乐休息等人道因素和能量、心理等因素，导致安排一个好的计划表非常烧脑
    
3. **市场切入点：** 市场上已经有很多类似产品（如Asana, Trello, Jira, [Monday.com](https://monday.com/)， 滴答清单等），为什么用户要选择我们？我们是**更便宜、更简单、更专业、还是针对某个垂直领域做了深度优化**？（这就是要找到产品的独特定位）
    我们免费的功能更多且考虑任务因素更多、算法更智能且更专业、生成的结果最优，并且给用户的体验感更好。
    
4. **“神奇时刻”：** 您希望用户第一次使用我们产品时，在哪个瞬间会发出“哇，这太棒了！”的感叹？
    首先前端界面要现代化简洁化且惊艳，操作过程更符合人性，生成的计划让人眼前一亮。在添加任务时给予用户更多可选的任务要素，使考虑因素更全面。与日历集成，生成后自动填充至日历，并从各种角度生成表等


## 第二阶段

1. **用户画像：** 能为我们描述一个典型的理想用户吗？（姓名、职业、工作模式、常用工具、他的目标和烦恼）。最好能有一个具体的人物原型。
    一个准备规划学业到期中考试的学生，一个进行近几年的职业规划的职场人士或者一个正在规划员工任务的领导等等。
    
2. **使用场景：** 他在**什么情况下**会想到使用我们的产品？（是每天开工前规划，还是随时记录，或是每周复盘？）
    当他们对接下来或长或短时间感到迷茫，需要使用工具使其变得清晰时
    
3. **竞争对手体验：** 您认为目标用户现在在用哪些替代方案？（可能是其他软件，也可能是Excel/纸笔）。他们对这些替代方案**最不满意**的地方是什么？我们如何做得更好？
    也许会用纸和笔或者Excel，但是那需要进行大量思考，而且还需要专业知识和计算，但不是每个人都专业，也不是每个人都希望花费太多时间在这上面。我们要做的就是用算法代替思考，用算法节约时间。

4. **用户旅程：** 一个用户从**听说** -> **试用** -> **上手** -> **付费** -> **推荐**的整个过程中，我们如何在每个环节让他感觉“爽”？
    上手容易且使用顺畅，当看到结果时会觉得太智能了。


## 第三阶段

1. **MVP功能：** 基于我们确定的核心价值，如果我们的第一个版本（MVP）只做**3个最核心的功能**来打动用户，您认为是哪三个？为什么是这三个？
    暂时只是这一个功能，因为我们的目标是快速占领市场，也许后续会加入其它功能，所以希望你们的产品易于拓展，开发模式适合迭代

2. **免费 vs. 付费：** 您对这个产品的商业模式有初步想法吗？是免费增值模式（Freemium）、一次性付费还是订阅制（SaaS）？
    大部分功能免费，但是更专业的内容需要付费

3. **付费门槛：** 如果我们采用免费增值模式，您认为哪个“杀手级”功能值得用户为之付费？是什么促使一个免费用户转化为付费用户？
    以后进军企业版可以收费

4. **扩展性：** 从长期来看，这个产品有哪些可以想象的扩展方向？（例如：集成日历、做数据报表、开发API、进军企业版等）
    数据报表和企业版，并且需要添加团队的规划功能
    
## 追问

### 在“核心价值主张”部分：

1. 【待决策-1】： 关于“算法更智能”，我们希望了解更具体的成功标准。例如，是优先保证“绝不延期”，还是优先保证“劳逸结合”？请明确1-2个核心优化指标。
    这应该交给用户选择，用户选择哪种我们的算法就按哪种标准进行规划。

### 在“MVP核心功能”部分：

2. 【待决策-2】： “任务要素更全面”列表中，哪些是MVP必须的？我们建议优先实现【名称、截止日期、预估耗时、紧迫度】，【前置任务】和【任务类型】是否必须放在MVP？
    任务或计划的多角度因素细化与剖析是重中之重，所以都是MVP，并且他觉得这些要素还不够，需要我们的人员科学的考虑一个任务或计划的量化因素。

### 在“商业模式”部分：

3. 【待决策-3】： “更专业的内容”具体指什么？这直接影响我们的技术选型和架构设计。可能的选项有：
A. 更深入的数据分析报表
B. AI预测任务完成时间
C. 无限量的任务清单
D. 优先客户支持
请协助明确优先级。
    需要优先A和D

### 在“项目目标”部分：

4. 【待决策-4】： 为了“快速占领市场”，我们是否有初步的用户增长目标（例如，3个月内获取10万注册用户）？这将影响我们在社交分享、病毒传播等功能上的设计权重。
    在学生和职场人士群体中快速传播。

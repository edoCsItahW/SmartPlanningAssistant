# 智能计划助手接口设计文档

## 1. 文档概述

### 1.1 文档目的
本文档定义智能计划助手系统的REST API接口规范，为前后端开发团队提供统一的接口标准，确保系统各模块间的数据交互一致性。

### 1.2 设计原则
- **RESTful风格**：遵循REST架构约束
- **一致性**：统一的请求/响应格式
- **安全性**：完善的认证授权机制
- **可扩展性**：支持版本管理和功能扩展
- **文档化**：完整的接口文档和示例

### 1.3 接口基础信息
- **基础URL**：`https://api.smartplan.com/v1`
- **认证方式**：Bearer Token (JWT)
- **数据格式**：JSON
- **字符编码**：UTF-8

## 2. 通用约定

### 2.1 请求头
```http
Content-Type: application/json
Authorization: Bearer {jwt_token}
X-Request-ID: {uuid}  # 请求追踪ID
X-Client-Version: 1.0.0  # 客户端版本
```

### 2.2 响应格式
#### 成功响应
```json
{
  "code": 200,
  "message": "success",
  "data": {...},
  "timestamp": "2024-12-19T10:30:00Z"
}
```

#### 错误响应
```json
{
  "code": 400,
  "message": "参数验证失败",
  "errors": [
    {
      "field": "title",
      "message": "任务标题不能为空"
    }
  ],
  "timestamp": "2024-12-19T10:30:00Z"
}
```

### 2.3 状态码说明
| 状态码 | 说明           |
| ------ | -------------- |
| 200    | 请求成功       |
| 201    | 创建成功       |
| 400    | 请求参数错误   |
| 401    | 未授权         |
| 403    | 禁止访问       |
| 404    | 资源不存在     |
| 409    | 资源冲突       |
| 500    | 服务器内部错误 |

### 2.4 分页参数
```json
{
  "page": 1,
  "size": 20,
  "total": 100,
  "pages": 5,
  "content": [...]
}
```

## 5. 任务管理接口

### 5.1 获取任务列表
```http
GET /tasks
```

**查询参数：**
- `page` (可选): 页码，默认1
- `size` (可选): 每页大小，默认20
- `status` (可选): 任务状态 (PENDING, IN_PROGRESS, COMPLETED, CANCELLED)
- `urgencyLevel` (可选): 紧急程度 (1-5)
- `importanceLevel` (可选): 重要程度 (1-5)
- `taskType` (可选): 任务类型 (CREATIVE, REPETITIVE, LEARNING, PHYSICAL, MEETING)
- `tag` (可选): 标签名称
- `sortBy` (可选): 排序字段 (createdAt, urgencyLevel, importanceLevel)
- `sortOrder` (可选): 排序方向 (asc, desc)

## 12. 接口版本管理

### 12.1 版本策略
- 版本号格式：`v1`, `v2`, `v3`
- 向后兼容性：小版本更新保持兼容
- 废弃通知：提前30天通知接口废弃

### 12.2 版本迁移
```http
# 旧版本
GET /api/v1/tasks

# 新版本
GET /api/v2/tasks
```

## 13. 接口限流策略

### 13.1 限流规则
| 接口类别 | 限制规则   | 说明           |
| -------- | ---------- | -------------- |
| 认证接口 | 10次/分钟  | 防止暴力破解   |
| 任务管理 | 100次/分钟 | 常规操作限制   |
| 计划生成 | 20次/分钟  | 计算密集型操作 |
| 数据分析 | 30次/分钟  | 数据查询操作   |
